# Mihon Vienna

基于 [Mihon](https://github.com/mihonapp/mihon) 的个人定制版漫画阅读器（Android）。

> 本项目是个人自用 / 二改项目，**不是** Mihon 官方发布版。在保留上游全部功能的基础上，重点增强了四个方向：一套 **「随机漫画机制」**（看看今天看什么）、一个 **「音声」频道**（在线流播音声内容）、以及新加入的 **「译名导入导出」**（让 AI 在外部帮你翻好中文名再导进来）与 **「本地漫画导入导出」**（本地库终于能放心折腾、整体搬迁）。源码基于 Apache-2.0 协议发布，详见 [LICENSE](LICENSE)。

## 与原项目（官方 Mihon）的对比

| 对比项 | 官方 Mihon | Mihon Vienna（本项目） |
| --- | --- | --- |
| 定位 | 通用漫画阅读器 | 以「本地源 + 随机点开即看」为核心的个人版 |
| 默认构建 | 多版本（`standard` / `release` 等） | `vienna` 版本，应用 ID 保持 `app.mihon.dev`，可原地升级 |
| 云图源插件 | 正常安装使用 | **照常能装能用**（联网追漫、下载、收藏、进度统计全保留） |
| 随机入口 | 仅有「随机排序」 | 全链路随机机制（浏览 / 漫画页 / 阅读器手势跳转） |
| 音声 | 无 | 独立 **音声频道**（在线流播 + 收藏 + 播放列表） |
| 译名 | 无 | **译名导入导出**（单本 / 全库，JSON / CSV，AI 外部翻译后导入） |
| 本地漫画导入导出 | 无 | **本地漫画导入导出**（文件夹 / 压缩包导入，自动建合集，篇目可移动） |
| 收藏 | 无 | 「收藏」清单 + 随机打开收藏作品 |
| 阅读器 | 官方功能 | 在官方基础上补充随机跳转手势、阅读进度会话、译名显示等 |

简单说：官方功能全保留，主要加了「随缘看什么」「听点有声」「让 AI 翻译名」「本地漫画导进导出」四件事。

## ✨ 重点一：随机漫画机制

这是本项目最核心的能力。目标很直接：**不想选了，一键「看缘分」**。整个机制贯穿「浏览 → 漫画页 → 阅读器」三层。

### 随机从不重复（冷却池）

随机不是无脑 `random()`，而是一个带冷却的池子：

- 最近 **1 小时内**抽过的漫画 / 章节会被暂时排除，避免「随机到刚才那本」的尴尬；
- 最多记录 **10 条**冷却项，先抽取的会随时间自然释放；
- 当所有候选都被冷却时，**自动释放整个池子重投**，保证任何情况下都能随机成功；
- 冷却记录持久化保存，退出应用再进来依然生效。

### 随机严格限定在「你正在看的范围」

- 从 **浏览列表** 进入：随机只会落在当前搜索 / 筛选结果里，不会跳到列表外；
- 从 **漫画页** 进入：优先随机当前列表，没有候选时回退到整个本地库；
- 排除当前正在看的这一本，绝不会「随机到自己」。

### 阅读器里的「滑一下，换一本」

这是体验上最有辨识度的部分。阅读本地源时，左右 / 上下滑动可以直接随机跳转到下一部：

| 手势 | 方向 | 随机池 |
| --- | --- | --- |
| Webtoon 横向滑动 | 左滑 | 当前本地源里「进行中」的漫画 |
| Webtoon 横向滑动 | 右滑 | 「收藏」清单 |
| 翻页器纵向滑动 | 上滑 | 当前本地源里「进行中」的漫画 |
| 翻页器纵向滑动 | 下滑 | 「收藏」清单 |

跳转细节也一一打磨过：

- **先选漫画、再选章节**：每个漫画被等概率选中，漫画内的候选章节再等概率选中，避免「章节多的大部头霸屏」；
- **跟随阅读筛选**：会沿用你在浏览页最后一次使用的阅读筛选（全部 / 未读 / 进行中 / 已看完），只在该池子里挑；
- **排除当前章节**：跳走后记住来源章节，下一次不会再落到同一章；
- **随机历史可回溯**：连续随机会留一条历史栈，可一步步退回之前的漫画和章节；
- **动画方向一致 + 预加载**：跳转进出动画与滑动方向对应，目标章节还会预先解压，打开不卡顿。

### 「收藏」清单

在漫画条目上**左滑**即可把这部作品加入「收藏」清单：

- 有独立的「收藏」清单页，可查看、管理、一键清空；
- 「随机打开收藏作品」永远从你亲手收藏的清单里抽；
- 阅读器右滑 / 下滑随机，同样以「收藏」清单为池。

## 🎧 重点二：音声频道

独立整合的在线音声内容流播模块，入口在「浏览」页的音声频道标签。底层是对接 **Kikoeru 风格后端**（`api.asmr-200.com`）的轻量客户端，走应用自带的 OkHttp 栈，并带 Cloudflare 503 自动重试与 401 自动登出。**注：该后端需要搭梯子才能访问。**

### 浏览与发现

- **四个标签页**：推荐 / 热门 / 最新 / 收藏，各自独立分页加载；
  - 「推荐」支持匿名 `UUID` 个性化推荐，登录后使用账号级推荐；
  - 未登录且无收听历史时，「推荐」会退回评分最高的作品，而不是和「热门」重复；
- **搜索**：关键词进入 URL path，支持 `$tag:标签$`、`$circle:社团$`、`$va:声优$` 高级筛选语法；
- **分类筛选**：社团 / 声优 / 标签三个分类页，按收录数排序，点选即跳转对应筛选结果；
- **排序**：发售日期、评分、下载量、入库日期、随机五种排序。

### 播放体验

- **在线流播**：Media3 通过应用 OkHttp 栈读取，支持流畅 / 高音质两档切换；
- **播放列表**：单曲或整部作品加入，跨屏常驻底部迷你播放条，支持「播放全部 / 随机播放」；
- **收听历史**：按作品聚合，记录进度，可「继续收听」；
- **歌词 / 字幕**：解析 `.lrc` / `.vtt` / `.srt` / `.ass` 字幕并随播放展示；
- **人性化细节**：定时睡眠（分钟级）、单曲循环、前进 / 后退 10 秒；
- **音量保护**：检测到未插耳机时自动压低音量并提示。

### 账号与同步

- 支持账号登录 / 登出（JWT `Bearer` 鉴权）；
- 登录后可同步账号级别的收听状态（想听 / 在听 / 听完 / 标记）；
- 本地收藏与账号收藏双向同步；未登录时收藏保存在本地。

## 🌐 重点三：译名导入导出（让 AI 帮你翻）

本地篇目始终保留来源中的原始名称，中文译名只是保存在同一篇目数据库记录上的「显示壳」；没有译名时自动回退原名。你可以用 AI 在电脑上把译名翻好，再一把导进手机。

### 导出 / 导入

- 漫画详情页右上角菜单可管理当前漫画的译名；「更多 > 数据与存储 > 本地库篇目译名」可管理整个本地库；
- 单本和全库均支持 **JSON** 与 **UTF-8 CSV**；CSV 可直接用 Excel / WPS 编辑，也接受英文表头（`manga_title`、`original_title`、`translated_title` 等）；
- 批量导入可同时选择多个从详情页导出的 JSON / CSV 文件；
- 支持「仅导出含空译名的漫画」：只保留至少有一个空译名篇目的作者目录，但会把该作者已有译名的篇目一并导出，方便外部翻译参考统一的命名风格；带 `referenceOnly` / `仅供参考` 标记的行不影响导入。

### 身份与安全

- 导入优先接受**完整篇目路径**匹配；数据库 ID 仅在原文件名和原始名称也一致时用于识别同设备内移动后的篇目，不会只凭同名瞎配；
- 空译名和无法可靠匹配的条目会被忽略，不会清掉软件内已有的译名，也不影响新篇目；
- 译名会和阅读进度、已读状态及自定义篇目封面一起跟随稳定的篇目 ID 迁移；
- 常规一键备份会包含当前磁盘上的本地漫画、译名、阅读进度、读完进度、总页数、自定义顺序及你选的篇目封面。

## 📥 重点四：本地漫画导入导出

本地库终于能放心折腾、也能整体搬迁了。既可从外部目录 / 压缩包一键导入，也能在本地条目之间移动篇目。

### 从文件夹或压缩包导入

- 支持从文件夹或 `ZIP / CBZ / RAR / CBR / 7Z / CB7 / TAR / CBT / EPUB` 导入漫画；
- 图片文件夹可在「**保留为文件夹**」（最快、保留原名方便继续管理）与「**打包为 CBZ**」（只收入图片、不重新编码、不损画质）之间选择；已是 Mihon 兼容的归档 / EPUB 则保持原格式直接导入；
- **默认复制、不删源文件**：导入成功后要不要删源文件由你**主动勾选**，且只有目标完整、数据库同步成功后才清理，安全第一；
- **自动建合集**：`根目录 / 作者 / 漫画` 这种两级别结构会自动按作者目录创建或复用合集；同名冲突默认**跳过**，不覆盖；
- **后台跑、可取消**：大库导入有进度条，返回通知栏也能看、能取消；取消不删还没导完的来源，任务可断点继续。

### 篇目移动

- 本地漫画详情页进入多选后，可直接把篇目「**移动到…**」其他条目，并支持现场新建条目；
- 移动会**原样保留**阅读进度、已读、书签、历史、译名、标记、备注和自定义封面等资料；
- 方案按「同一存储原生移动 → 不可用时复制到目标临时位置 → 校验 → 正式落盘 → 删源」的顺序执行，失败可回滚、不删唯一来源；
- 移动后只刷新来源与目标条目，不触发无关全库扫描。

## 其他个人定制项

在 Mihon 基础上还调整 / 增加了这些功能：

- **本地源优先**的个人主版本（`vienna`），应用 ID 保持 `app.mihon.dev`；
- 阅读器增强：随机阅读历史、阅读进度会话、滑动手势（普通翻页 + 随机跳转）、**顶栏显示翻译后的篇目标题**、Webtoon 布局选择等；
- 浏览页增强：刷新章节目录、最近阅读、按日期分组等；
- 历史 / 搜索增强：搜索历史、一键清除历史等；
- 章节**自然排序**支持小数：`1`、`1.5`、`2` 按数值排，不再把 `10` 排到 `2` 前面；
- 本地库抗「空读」：存储提供器暂时返回空目录时，不会清空你最后一次正常的索引或界面结果；
- 更多个人设置项：我的列表（「收藏」清单）、章节标志等。

具体变更可查看提交历史与 [CHANGELOG](CHANGELOG.md)。

## 构建

需要 JDK 17+ 和 Android SDK。

```bash
# 个人主版本（默认，应用 ID：app.mihon.dev，可原地升级）
./gradlew app:assembleVienna
```

其他变体（`localFirst` / `release` 等）仅在明确需要时构建。连接的主力设备建议使用 `arm64-v8a` APK。
