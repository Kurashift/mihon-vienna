# Mihon Personal

基于 [Mihon](https://github.com/mihonapp/mihon) 的个人定制版漫画阅读器（Android）。

> 本项目是个人自用 / 二改项目，**不是** Mihon 官方发布版。在保留上游全部功能的基础上，重点增强了两个方向：一套 **「随机漫画机制」**（看看今天看什么）和一张 **「ASMR 页面」**（在线流播音频）。源码基于 Apache-2.0 协议发布，详见 [LICENSE](LICENSE)。

## 与原项目（官方 Mihon）的对比

| 对比项 | 官方 Mihon | Mihon Personal（本项目） |
| --- | --- | --- |
| 定位 | 通用漫画阅读器 | 以「本地源 + 随机点开即看」为核心的个人版 |
| 默认构建 | 多版本（`standard` / `release` 等） | `personal` 版本，应用 ID 保持 `app.mihon.dev`，可原地升级 |
| 随机入口 | 仅有「随机排序」 | 全链路随机机制（浏览 / 漫画页 / 阅读器手势跳转） |
| 音频 | 无 | 独立 **ASMR 页面**（在线流播 + 收藏 + 播放列表） |
| 好本子 | 无 | 「好本子清单」+ 随机打开好本子 |
| 阅读器 | 官方功能 | 在官方基础上补充随机跳转手势、阅读进度会话等 |

一句话总结：**官方 Mihon 负责「怎么看」，Personal 版在此基础上把「今天看什么」这件事做顺。**

## ✨ 重点一：随机漫画机制

这是本项目最核心的能力。目标很直接：**不想选了，一键「看缘分」**。整个机制贯穿「浏览 → 漫画页 → 阅读器」三层。

### 随机从不重复（冷却池）

随机不是无脑 `random()`，而是一个带冷却的池子：

- 最近 **1 小时内**抽过的漫画 / 章节会被暂时排除，避免「随机到刚才那本」的尴尬；
- 最多记录 **10 条**冷却项，先抽取的会随时间自然释放；
- 当所有候选都被冷却时，**自动释放整个池子重投**，保证任何情况下都能随机成功；
- 冷却记录持久化保存，退出应用再进来依然生效。

### 随机严格限定在「你正在看的范围」

- 从 **浏览列表** 进入：随机只会落在当前搜索 / 筛选结果里，不会跳到列表外；
- 从 **漫画页** 进入：优先随机当前列表，没有候选时回退到整个本地库；
- 排除当前正在看的这一本，绝不会「随机到自己」。

### 阅读器里的「滑一下，换一本」

这是体验上最有辨识度的部分。阅读本地源时，左右 / 上下滑动可以直接随机跳转到下一部：

| 手势 | 方向 | 随机池 |
| --- | --- | --- |
| Webtoon 横向滑动 | 左滑 | 当前本地源里「进行中」的漫画 |
| Webtoon 横向滑动 | 右滑 | 「好本子」清单 |
| 翻页器纵向滑动 | 上滑 | 当前本地源里「进行中」的漫画 |
| 翻页器纵向滑动 | 下滑 | 「好本子」清单 |

跳转细节也一一打磨过：

- **先选漫画、再选章节**：每个漫画被等概率选中，漫画内的候选章节再等概率选中，避免「章节多的大部头霸屏」；
- **跟随阅读筛选**：会沿用你在浏览页最后一次使用的阅读筛选（全部 / 未读 / 进行中 / 已看完），只在该池子里挑；
- **排除当前章节**：跳走后记住来源章节，下一次不会再落到同一章；
- **随机历史可回溯**：连续随机会留一条历史栈，可一步步退回之前的漫画和章节；
- **动画方向一致 + 预加载**：跳转进出动画与滑动方向对应，目标章节还会预先 `warm-up` 解压，打开不卡顿。

### 「好本子」清单

在漫画条目上**左滑**即可把这部作品标为「好本子」：

- 有独立的「好本子清单」页，可查看、管理、一键清空；
- 「随机打开好本子」永远从你亲手收藏的清单里抽；
- 阅读器右滑 / 下滑随机，同样以好本子清单为池。

## 🎧 重点二：ASMR 页面

独立整合的在线音频流播模块，入口在「浏览」的 ASMR 标签页。底层是对接 **Kikoeru / Asmr.one 风格后端**（`api.asmr-200.com`）的轻量客户端，走应用自带的 OkHttp 栈，并带 Cloudflare 503 自动重试与 401 自动登出。

### 浏览与发现

- **四个标签页**：推荐 / 热门 / 最新 / 收藏，各自独立分页加载；
  - 「推荐」支持匿名 `UUID` 个性化推荐，登录后使用账号级推荐；
  - 未登录无历史时，「推荐」会退回评分最高的作品，而不是和「热门」重复；
- **搜索**：关键词进入 URL path，支持 `$tag:标签$`、`$circle:社团$`、`$va:声优$` 高级筛选语法；
- **分类筛选**：社团 / 声优 / 标签三个分类页，按收录数排序，点选即跳转对应筛选结果；
- **排序**：发售日期、评分、下载量、入库日期、随机五种排序。

### 播放体验

- **在线流播**：Media3 通过应用 OkHttp 栈读取，支持流畅 / 高音质两档切换；
- **播放列表（待播列表）**：单曲或整部作品加入，跨屏常驻底部迷你播放条，支持「播放全部 / 随机播放」；
- **播放历史**：按作品聚合，记录进度，可「继续收听」；
- **歌词 / 字幕**：解析 `.lrc` / `.vtt` / `.srt` / `.ass` 字幕并随播放展示；
- **人性化细节**：定时睡眠（分钟级）、单曲循环、前进 / 后退 10 秒；
- **音量保护**：检测到未插耳机时自动压低音量并提示。

### 账号与同步

- 支持账号登录 / 登出（JWT `Bearer` 鉴权）；
- 登录后可同步账号级别的收听状态（想听 / 在听 / 听完 / 标记）；
- 本地收藏与账号收藏双向同步；未登录时收藏保存在本地。

## 其他个人定制项

在 Mihon 基础上还调整 / 增加了这些功能：

- **本地源优先**的个人主版本（`personal`），应用 ID 保持 `app.mihon.dev`；
- 阅读器增强：随机阅读历史、阅读进度会话、滑动手势（普通翻页 + 随机跳转）、Webtoon 布局选择等；
- 浏览页增强：刷新章节目录、最近阅读、按日期分组等；
- 历史 / 搜索增强：搜索历史、一键清除历史等；
- 更多个人设置项：我的列表（好本子清单）、章节标志等。

具体变更可查看提交历史与 [CHANGELOG](CHANGELOG.md)。

## 构建

需要 JDK 17+ 和 Android SDK。

```bash
# 个人主版本（默认，应用 ID：app.mihon.dev，可原地升级）
./gradlew app:assemblePersonal
```

其他变体（`localFirst` / `release` 等）仅在明确需要时构建。连接的主力设备建议使用 `arm64-v8a` APK。
