# 同名导入与空合集回归

遇到同名项只确认一次。默认跳过；勾选「替换已有文件」才替换能唯一匹配的同格式归档文件。新文件先校验，再原子替换旧文件；不支持原子替换的存储不覆盖。替换不重建篇目记录，保留阅读进度、已读、书签、标记、译名和手选封面。

文件夹还在，合集就留在「全部」并显示「0 篇」。移走最后一篇不会删除源文件夹。删完篇目时可以主动勾选「同时删除空文件夹」，会列出一并删除的封面和元数据；无法确认安全时保留文件夹，并在结果中说明。散页合集默认只删正文图片。仅通过文档提供器访问的文件夹没有非递归删除保证，此时保留目录。

## 真机回归

只用测试副本，不在主库测试删除。

1. 给蓝色 `Refresh same.cbz` 设置进度、书签和标记。从详情页导入同名红色副本，先选跳过，再勾选替换。预期第一遍仍是蓝色；第二遍打开是红色、篇目没重复、进度和标记都在。下一批仍会询问。
2. 从本库导入多个合集，混入同名归档、异格式同名项和新篇目。预期只弹一次确认；符合条件的文件替换，异格式保持原样，新篇目正常导入。
3. App 内移走一部合集的最后一篇；再用两个单篇测试合集验证删除。一个不勾选「同时删除空文件夹」，确认结果仍在详情页，返回本库后卡片显示「0 篇」。另一个勾选再确认，目录删掉后应自动回「本库」并显示删除结果，原卡片消失。如果结果提示目录保留，则仍应留在详情。移动后源卡显示「0 篇」、目标保留进度；散页合集默认不随正文删除封面和附件。
4. 用文件管理器新建、清空、移除三个测试目录，各执行一次「刷新本库」。预期前两个显示「0 篇」，移除目录的卡片消失。空卡可按标题搜索，不出现在阅读状态筛选和随机结果里。重启后从空卡导入，核对篇目数和封面。
5. 删除 `QA Move To` 的最后一篇，不勾选删除文件夹。确认它既出现在「移动到」，也出现在本库导入的「选已有的」。从 `QA Move From` 移入唯一篇目，目标应显示 1 篇，源合集应留在本库并显示「0 篇」。

旧文件丢失、已有篇目状态重置、空文件夹被隐藏、附件被误删、筛选数量和列表对不上，均算回归。失败注入由单测验证；文档提供器、真机显示和刷新耗时需要设备验收。
