# Mihon Vienna 2.3.1

## ⚠️ 装之前先备份

**这一版不能直接覆盖安装，需要先卸载再重装。**

**第一步，先在旧版里备份：设置 → 数据与存储 → 创建备份**

**然后依次操作：卸载旧版 → 安装新版 → 从备份恢复**

进度、已读、书签、书架分类都能找回。漫画文件不会丢。

---

## 播放界面重做

进度条和音量条以前又粗又分不清调到了哪。现在：

- **进度条**是一条细线，能看出**缓冲到哪了**（以前只显示播放位置）
- **音量条**是一格一格的档位，填了几格就是几档
- 两者形状不同，一眼能分清

## 播放起步更快

从历史记录或播放列表点开一首很久没听的曲子，**不再等网络**。以前每次播放都要先联网解析一次地址，5 分钟缓存一过就要等。

## 本地库修复

- **全选不再漏一个**：没有篇目记录的作品在选中时被静默跳过，列表显示着它、全选却不含它
- **计数不再滞后**：以前要切一下筛选才追上列表
- **删掉的作品不再自己回来**：重启后卡片复活的根因是索引没清干净
- **删空目录不再残留**：移动篇目后留下的空目录正是残留卡片的来源

## 其他修复

- **长按作品标题不再误选篇目**
- **删除本地作品不再被「文件已不在」挡住**
