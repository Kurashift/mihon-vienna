# Mihon Vienna 2.4.0

> 撤销覆盖到书架、已读、书签、标记、个人清单、历史与分类，阅读器删页也能撤回；本地库能读没有章节目录的单篇作品；从「本库」退出再进，启动页从 5 秒降到 0.7 秒。

**覆盖安装即可，不用卸载。** 这一版没有动用户数据，也没有改签名。

## 撤销：一个胶囊退回一步

书架移出、标记已读／未读（多选、左滑、读到此篇、此篇之后）、加去书签、重复标记、好本子、个人清单的移除与清空、标记清单与好本子清单的移除和清空、已读完篇目的标记未读、清除历史、删除分类，执行后都会弹一条 5 秒的胶囊。点「撤销」回到操作前，按住胶囊暂停计时，被下一条提示顶掉就不再撤销。

撤销写回的是**操作前的原值**，不是反着再做一遍：

- 已读状态连同续读位置和读完时间一起回写。反过来做会把读到一半的篇目顶到末页。
- 标记按原来的对象放回，标记时间不变，清单按标记时间排序时不会跳位置。
- 移出书架恢复加入日期与分类成员。重新「加入书架」会把加入日期刷成现在，作品会跳到按日期排序的最前面。
- 清除历史按绝对值写回。用累加式的写入恢复，每条记录的阅读时长会翻倍。

删除分类要重建：新分类拿不到旧 id，所以成员、标签栏里的位置、五个分类过滤器里的勾选（全局更新的包含／排除、下载新篇目的包含／排除）和默认分类设置，撤销时全部指向新 id；撤销窗口里又建了一个同名分类的话，合并进去，不会多出一行同名的。

三处确认弹窗换成了撤销胶囊，因为这些动作都能完整恢复，胶囊里直接说清下载与阅读进度保留：移出书架、个人清单的移除与清空、已读完篇目的标记未读。

**一个例外：** 开着「标记为已读后删除下载」时标记已读，不给撤销。篇目文件已经删了，撤销只能恢复已读状态，文件回不来，所以只报一句结果，不弹胶囊。删除已下载篇目和本地文件仍然保留确认弹窗，磁盘上的东西撤不回来。

## 阅读器：删掉的页能撤回

长按页面可以删除普通图片，也可以删 ZIP/CBZ 里的图片条目；最后一页和只读格式不显示删除入口。连续删除合并成一批，最后一次操作之后保留 5 秒撤销窗口，按住提示栏暂停、松手重新计时。

退出阅读器后提示还在，后台提交这一批：普通图片不复制，压缩包按章节流式重写，替换失败回滚原文件，提供器拒绝回滚时保留备份。页码、阅读进度和压缩包的页列表缓存会跟着修正。

## 本地库：没有章节目录的单篇作品

有些作品目录里直接就是图片或一个压缩包，没有章节子目录。以前这类目录要么不算作品，要么每次都要重试一遍才认。现在它算 1 章：虚拟章 `.__single__`，落库之后 url 不再变，进度、标记、译名都挂在它身上。

- 目录里的散图就是这个虚拟章的页；app 自己写的 `cover.jpg` / `cover.webp` 会被排除，封面不会变成第 1 页。
- 没有 `cover.*` 的单篇作品，直接用第 1 页当封面，卡片不用再进详情页才完整。
- 删掉单篇唯一的一章，等于删掉整部作品：作品行和卡片一起消失，动作条重新给出删除入口。
- 列表面、页数、章节列表和空目录判定共用同一次遍历，原来每个单篇都要付的 1.25 秒重试没有了。

## 启动页：从「本库」退出再进不再等 5 秒

2.3.8 开始记住上次的 tab。从「本库」退出再进来，就落在本库——然后启动页要停满 5 秒。

启动页什么时候撤，取决于当前页面有没有告诉 Activity「内容好了」。书架、更新、历史、浏览四个页面都会说，本库和更多从来不说，所以只能等 5 秒兜底超时。2.3.8 之前冷启动永远落在书架，这条路径走不到；记住 tab 之后才第一次出现。

现在这两个页面也会说了：本库在自己的列表送达时撤启动页，更多没有要等的数据，页面一出来就撤。同一台设备、553 部作品 / 4036 个篇目文件，冷启动实测：

| 落在哪一页 | 2.3.9 | 2.4.0 |
| --- | --- | --- |
| 本库 | 5.0–5.7 秒 | 0.69–0.75 秒 |
| 书架 | 秒进 | 0.76 秒（未回归） |
| 更多 | 5 秒 | 0.43 秒 |

启动页消失时首屏已经是完整封面网格，没有先空白再填的二次等待。

## 书架「有更新了」不再误报

本地库刷新完成之后，书架横幅不会再对着刚刷完的那次变化再喊一遍「有更新了」。判断基准换成了上次成功刷新提交的目录签名，而不是内存里上一次读到的目录——后者记的还是变化之前的样子，于是刚刷新过的变化被当成新变化，横幅请你去刷新一件已经做完的事。
