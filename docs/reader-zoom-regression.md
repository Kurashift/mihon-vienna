# 条漫双击缩放回归

## 行为变化

以前横屏先按图片是否接近满屏高度选择下一档，再把目标缩放限制到完整显示宽度以内。1920×1280 的阅读区域显示一张适宽后高 1080 的图片时，两次计算都可能停在原大小。现在先计算两档可到达的大小：通常保持占满高度和八成高度；图片太宽时，使用完整显示大小和它的八成。达到原有最小缩放限制的长图，以较大一档代替无法到达的较小档。

横屏用双指调到其他大小后，下一次双击先回到标准阅读大小。竖屏保留默认大小与两倍放大之间切换。开启“不允许缩得比默认更小”时，横屏也使用默认大小与两倍放大，不再进入低于默认大小的高度切换。

再次双击可反向切换正在执行的动画；双指缩放、窗口变化和离开阅读器会取消旧动画，旧动画结束回调不能把画面拉到过期目标。横屏缩放继续沿用现有的画面中心位置保持方式；小窗变化后重新计算缩放并保持中心所在页面位置。

阅读器设置将两个开关移入独立“缩放”组。“双击放大”改名为“双击缩放”，“禁用缩小”改名为“不允许缩得比默认更小”，并说明放大的图片仍可还原。全局阅读设置使用同样文案和独立分组。偏好键和默认值不变：双击开启、缩小限制关闭；不覆盖已有选择。

图片解码、预载、条漫滚动和惯性、随机切换、双页拆分、已读规则、历史及章节同步不在本次改动范围。

## 手动回归

只用 Vienna-Test-20261116 等独立测试副本。若测试作品不在书架，可从本地源列表搜索名称打开。缩放时选择篇目中间的页面，避免第一张或最后一张的边界影响位置判断。

1. 打开测试篇目，轻点中央调出工具栏，进入齿轮的“阅读模式”页。预期“双击缩放”和“不允许缩得比默认更小”出现在“缩放”组。勾选前者、取消后者，关闭设置；全局“设置 → 阅读”中的开关应显示相同状态。
2. 横屏全屏打开原来会双击不动的宽图，连续双击数次。预期两档稳定往返，左右内容完整，不停在同一大小；用普通比例图片对照，仍按满高和八成高切换。再用双指放大，双击后回到标准阅读大小，第二次进入较小档。
3. 动画尚未结束时再双击，预期平滑反向；动画过程中用双指缩放，预期立即跟随手指，松手后旧动画不把画面拉回去。缩放前后正在看的内容位置应保持，无白块、跨页或错误已读。
4. 竖屏双击，预期放大与还原往返。开启“不允许缩得比默认更小”后再横屏双击，预期放大与还原都有效，双指不能缩到默认大小以下。关闭“双击缩放”后，双击应不再缩放，双指仍可用。结束后恢复双击开启、缩小限制关闭。
5. 横屏与竖屏、小窗与全屏之间切换，再连续下滑、反向翻回、跨篇目、拖进度条、缩放并退出续读。预期重新适应窗口，继续阅读和续读落点与原规则一致。不会跳回篇目开头或突然被旧动画拉走。

原地不动、动画中断后跳到旧大小、双指被动画拉扯、放大后无法还原、关闭限制后仍无法缩小、白块、横向裁图、跨页、错误已读、续读位置变化均算回归。用户操作手机，agent 检查日志；不使用主库进行改名、删除或故障注入。

## 自动验证与真机边界

自动测试覆盖极宽图不动的具体尺寸、正常满高与八成高、原有最小缩放限制、不同窗口尺寸、未测量页面、双指后的回归方向、动画中反向目标、默认及四种已有开关组合；使用 Android Animator 的模拟对象检查取消、替换与旧回调隔离。

自动测试不能证明实际帧率、双击识别和缩放时的画面位置。手势响应、快速反向、旋转与小窗、页边界、滚动惯性和退出续读仍待同一台手机操作确认。没有设备结论前不宣称手感改善。
