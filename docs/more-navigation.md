# 「更多」入口对照与真机回归

## 入口对照

下表从「更多」起算。设置搜索可以进入各组设置，点结果后按返回，回到原查询。作品详情、阅读器、系统选择器、系统权限页和站外链接是本次核对的终点。

| 原入口 | 现入口 | 可操作到的终点 |
|---|---|---|
| 首页的仅显示已下载、无痕模式 | 原位 | 点击整行切换；无痕模式保留暂停记录阅读历史的说明 |
| 个人清单 → 标记、好本子 | 原位 | 按作品或篇目搜索、打开作品或阅读、导出全部或选中项、移出或清空并撤销；标记清单另有删除本地文件，确认框显示范围 |
| 个人清单 → 已读完篇目 | 原位 | 搜索、导出、打开作品、按作品看篇目、多选、全选、反选、改为未读和撤销 |
| 分类、设置 → 书架 → 编辑分类 | 两个入口共用原页面 | 添加、重命名、拖动排序、删除；重名时保留输入 |
| 下载队列 | 原位 | 暂停、继续、全部取消，按上传日期或篇目编号升降序；单篇或整部置顶置底、取消单篇 |
| 统计 | 原位 | 概览、本地库、书架与下载、进度平台 |

## 真机回归

1. 手机打开「更多」，依次进入个人清单、分类、队列和统计并返回。清单为空时入口仍可点，有数据时显示数量。打开标记清单多选，核对「移出清单」和「删除本地文件」的对象。
2. 搜索「裁剪边缘」，先点条漫，再返回点单页式。每次应打开对应模式并定位到该行，返回保留搜索词和滚动位置。切换编辑模式后核对默认阅读模式。进入阅读器连续下滑、反向翻回、跨篇、拖进度条、双击缩放、退出续读。
3. 在测试副本进入「数据与存储」，导出书架 CSV 和译名并核对内容。导入重名篇目，检查跳过与取消；创建备份，选取该备份查看还原预检。取消选择文件应留在原页。涉及删除原件、还原或覆盖只使用测试副本。
4. 打开「权限」，从系统通知设置返回并核对状态；在「关于 → 帮助」打开引导、返回，再检查更新。平板双栏重复搜索、跳转和返回，放大系统字体检查按钮和路径是否截断。
5. 在「书架 → 本地作品」切换封面网格，回到测试作品看布局。在存储空间查看生成状态，运行中可取消。打开设置目录本身应当安静，不启动封面生成、导入或备份。

搜索定位到同名的另一组、返回丢失查询、修改模式串到另一组、取消选择却开始写入、清单移除导致文件消失，均算回归。自动验证覆盖设置行定位、现有业务单测、数据库迁移、格式与 Vienna 编译；系统文件选择器、真机手势和大字体排版需人工操作确认。
