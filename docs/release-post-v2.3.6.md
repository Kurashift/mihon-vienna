# Mihon Vienna 2.3.6

> 更新可以在应用里直接下载并安装；音声播放页的进度条能拖了。

**覆盖安装即可，不用卸载。**

---

## 应用更新：在应用内下载并安装

以前点「更新日志」会跳到浏览器，自己找对应架构的包，下完再交给系统安装器。现在弹窗里的「下载并安装」把这三步做完：

- 用应用自己的网络栈下载这台设备对应 ABI 的包。arm64 包 27.0 MB，实测 VPN 下 550 KB/s，约 50 秒
- 下完比对发布页给出的 SHA-256（GitHub 给每个附件算的那个 digest）。不一致就删掉重来，不会把一个坏包交给安装器
- 校验通过后拉起系统安装器。第一次会要求允许本应用「安装未知应用」，允许之后回来点一次「安装」——已经下好的包留在本地，不会重下第二遍

下载过程中可以取消。「更新日志」从按钮挪到正文里的一行链接，按钮位留给下载。

这一版仍然只在 GitHub 上放包，国内不挂代理的话更新检查本身也连不上，和以前一样需要自己处理网络。

## 音声：播放页进度条

拖动进度条时圆点走到一半就弹回原处，松手后跳转也落在那个位置；点字幕跳转却正常。

原因是手势的回调只在页面第一次组合时被捕获一次，调用方用来夹取位置的时长就冻结在那一刻：页面刚打开时是 0，在队列里切歌之后是上一首的长度。现在回调读的是当前状态，夹取用当前时长。阅读器那条进度条本来就是这么写的，所以它没有这个问题。

同一处陷阱还影响音量条，一并改掉。

## 音声：播放页的队列按钮挪到播放键一排

从顶栏挪到播放键那一排，跟在「词」按钮右边。队列是听的时候顺手用的，和循环、睡眠定时器是一类；顶栏只剩收藏一个图标。

## 音声：列表标签的间距

列表卡片底部的标签，2 字标签之间隔 17dp、5 字标签只隔 5dp，同一行既挤又散。量下来一行里的间距是 4.0 / 4.9 / 5.8 / 6.7 / 10.4 / 11.3 / 17.1 / 22.6dp。

标签用的是 `Surface(onClick)`，它会为触摸预留 48dp 槽位、把背景居中画在槽里，短标签两侧那圈空白就叠在 4dp 间距上。改成和详情页标签一样的画法，间距恒为 4dp。
