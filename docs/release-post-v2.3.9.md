# Mihon Vienna 2.3.9

> 小更新，可以跳过不装。只把 2.3.8 改过的「跳过已读篇目」恢复成 2.3.7 的手感，那个手感更好。

**覆盖安装即可，不用卸载。** 这一版没有动用户数据，也没有改签名。不装这一版也没有关系，其他功能与 2.3.8 完全一样。

---

## 跳过已读篇目：回到 2.3.7 的手感

2.3.8 把「跳过已读篇目」改成了只在往后接续时跳到下一篇未读，往回翻保持紧邻。用起来有两点别扭：

- 往前跳过了几篇，往回一返却只退一格，落进一篇这次会话根本没打开过的邻近篇目，而不是刚才在读的那一篇。手往回滑的时候，想要的是回到刚看过的，不是旁边陌生的一篇。
- 同一个章节导航栏，「下一篇」一次跨几篇，「上一篇」一次退一篇，两个按钮步长不一致。

2.3.7 的做法是**打开阅读器时一次性把已读篇目从链条里去掉，整个会话链条不再变**，前后两个方向走同样的步长。往前跳一步、往回退一步就能回到起点，跨篇目的形状也和普通翻章完全一样。这个往返闭环的手感更好，也更符合「跳了一步，退一步就回去」的直觉。

所以这一版把 2.3.8 的改动完整退回：静态过滤、`chapterList[pos±1]` 的前后篇、三元结构的 `ViewerChapters`，以及设置副标题「上下方向都会跳过；想逐篇重读请先关闭」，都逐字恢复到 2.3.7 的状态。

其余改动一律保留：本地库 webp 的导入与封面、音声队列手风琴、退出阅读器回到原来的导航页、双指缩放调每行数目，都与 2.3.8 相同。
