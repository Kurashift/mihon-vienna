# 音声播放页内嵌视频

音声作品里有少量带画面的条目（DLsite 的「動画版」「影片版」），后端把它们当成普通 `audio` 节点返回，所以曲目列表里一直有它们，只是播放时只出声。这份文档记录现在的做法和为什么这样做。

## 实测数据

以 RJ335418 的 `【视频版】萝莉后宫.mp4` 为例：

| 项 | 值 |
| --- | --- |
| 大小 / 时长 | 1,021,725,936 B / 3754 s |
| 轨道 | `avc1`（H.264）+ `mp4a`（AAC） |
| 容器 | non-faststart，`moov` 在文件尾部 |
| 响应头 | `Accept-Ranges: bytes`，`Content-Type: audio/mpeg`（原类型 `video/mp4`） |

后两条决定了三件事：首帧要先发一次尾部 Range 请求；容器不能靠响应头判断；地址里的扩展名是唯一可靠的格式线索。

## 决策

**输出面用 TextureView。** 它和封面同属页面内容，能裁剪成同样的 8dp 圆角、能跟着 `materialSharedAxisX` 页面转场滑动、能在方形封面与 16:9 画面之间做高度动画。`SurfaceView` 是窗口下面的独立图层，这四项都不成立，转场时会在滑动的内容中间留一块不动的黑块。

**视频不进磁盘缓存。** 缓存上限 512 MiB，一个作品就 1 GiB，写进去会把用户正在听的音频全部挤掉，而且永远装不下。视频走 `ProgressiveMediaSource` + 同一个 OkHttp 数据源，直接流式读取。

**视频轨跟随输出面启停。** 没有 Surface 时把视频轨禁用（阅读器、队列页、息屏、后台）。解码到不存在的画面上只费电，而且后台解码失败会走错误路径。播放页挂上 Surface 时再打开。

**同名音视频不再互相顶掉。** 优先级表里 mp4 一直排最后，同一组里若有 `本編.wav` 和 `本編.mp4`，以前只剩 wav，视频永远打不开。现在视频作为同一曲目的第二行保留，字幕共用。

**不改持久化模型。** 视频身份由 `mediaStreamUrl` 的扩展名派生（`isVideoSource`），不往 `AudioPlayItem` 加字段——历史和播放列表都是 JSON 存的，加字段就得考虑旧数据。

**不做画中画。** `MainActivity` 没有 `supportsPictureInPicture`，属于独立工作量。

## 行为

队列可以音视频混排，切曲时按下面的顺序更新界面：

1. `onMediaItemTransition` 按新曲目扩展名乐观置 `hasVideo`，避免每切一首就塌回方形再撑开；
2. `onTracksChanged` 用真实轨道校正（音频型 mp4 会被纠正）；
3. `onVideoSizeChanged` 给出真实比例，舞台高度动画过渡；
4. `onRenderedFirstFrame` 撤掉封面。

| 场景 | 结果 |
| --- | --- |
| 音频 → 视频 | 舞台从方形动画到 16:9，先显示封面与缓冲圈，首帧到达后换成画面 |
| 视频 → 音频 | 画面淡回封面，比例动画回方形 |
| 视频 → 视频（换作品） | 封面换新作品，比例重算，中间保留上一帧直到新首帧 |
| 同名 wav + mp4 | 两行都在，视频行带「视频」徽标 |
| 音频型 mp4 | 校正为无画面，只显示封面 |
| 设备解不了该编码 | 塌回封面并提示「该视频无法解码，仅播放音频」，**不跳曲**、不循环重试 |
| 播放页不在前台（队列页 / 后台 / 息屏） | 只出声，视频轨禁用；回到播放页重新挂面并续播 |
| 阅读器悬浮窗 | 只出声，工作名旁显示「视频」徽标；点开播放页后从当前进度出画面 |
| 全屏 | 手机横屏 + 隐藏系统栏，控件 3 秒后淡出，点画面唤回；退出按钮常驻右上角，返回键先退全屏 |
| 全屏中切到音频曲目 | 自动退出全屏，方向与系统栏恢复（只在曲目真的换了时判断，不看轨道瞬时状态） |

## 边界

- **首帧慢**：`moov` 在尾部的 1 GiB 文件，起播要先读尾部索引。视频起播的缓冲超时从 20 s 放宽到 60 s，且超时只报错、不跳下一曲。
- **编码失败**：只在渲染器报的是视频格式时介入，禁视频轨后重新 prepare，同一地址只做一次。
- **离开页面**：`detachVideoOutput` 用调用方令牌校验，两个播放页叠在一起时，离开的那个不会摘掉还亮着的那块。
- **全屏与方向锁**：方向只由一处 `LaunchedEffect` 决定（全屏横屏 / 普通竖屏 / 平板不动），进页面时记下原值，离开时还原。
- **暂停后回到页面**：TextureView 重建后没有帧，封面会盖在画面上，直到重新出帧。
- **蜂窝流量**：不拦、不提示。1 GiB 的视频按需播放。
