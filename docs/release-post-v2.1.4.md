# 这是什么？

> 这是一款全方位为阅读本地收藏的涩涩本子体验所特化的 app。
> 
> （虽话是这么说，但它依旧保留着原版 Mihon 的云图源插件——你照样能安装「拷贝漫画」「3hentai」等云图源网站，联网追漫画、搜云端本子。）

话不多说，我直接简要说说核心特化：

---

## ① 阅读器加入随机机制！

**右滑**：收藏清单随机抽。想冲刺？在收藏本子对应的作者们旗下本子开随机池！不用翻目录翻到贤者时间。
**左滑**：未读 / 进行中随机下一部。解决选择困难症？茫茫大海不知道看什么？直接随机未读完的下一本！

**为什么要这样？** 因为本子和长篇漫画的体验是不同——本子大多是短篇，追求短平快，这样能更方便你随意控制节奏。

---

## ② 内置 ASMR 模块（需要梯子）

连接了 Kikoeru 网站。
这是个独立模块，也可以在本子阅读器中悬浮窗后台播放；想的话，看本子时放点纯娇喘背景声助兴，我觉得是挺不错的。

**为什么要这样？** 因为我一直觉得单调地汲取视觉信息还不够有意思；既然听觉还有空闲，那么就有上升空间！

---

## ③ 译名导出导入

篇目标题一键导出，把导出的 JSON 用 AI 翻成中文，再导进手机；在漫画详情页里打开"显示中文"，就能给本子们赋予中文名。
你只需要：一、导出 JSON 或 CSV；二、把导出的东西丢给 AI，让它不破坏文件结构地翻译；三、导回 AI 返还的 JSON 或 CSV。

**为什么要这样？** 一堆罗马音或日语确实看不懂含义。虽然看封面图很直接，但果然还是有了中文意思，能更多 get 到本子的内涵。

---

## ④ 一键导入本地本子库

现在可以手动导入本地本子，并自动转成 Mihon 需要的文件路径形式。

**为什么要这样？** Mihon 原生的本地路径比较特殊，没法直接导入常见的"文件夹 + 图片"形式；它需要的是父级文件夹下 = 封面图片 + 详细篇目的本子文件夹，本子文件夹下面才是图片。
