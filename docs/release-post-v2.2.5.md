# Mihon Vienna 2.2.5

> 小版本：修好「几百本只导出一百多份」的译名导出问题，并在本地库菜单里加上导入导出入口。

---

## 🐛 译名导出：不再漏掉没打开过的本子

有用户反馈：本地库五百多本，导出译名只出来一百多份。

原因找到了。导出一直在拿**数据库里有没有记录**当作「这本存不存在」的依据，而从没点开过、也没刷新过的本子，数据库里根本没有它的篇目记录——于是磁盘上明明躺着，导出却直接跳过。你之前导出正常，只是因为你的本子基本都打开过。

现在改成以**磁盘扫描结果**为准：

- 数据库里已有的篇目照旧导出，译名、页数都不动
- 数据库还没记录的文件，按扫描到的文件名一起列进模板（`stable_key` 写 `0`，表示还没有篇目编号）

顺带修了两处相关的：

- **提示里的数量和文件内容不一致** —— 以前是各算各的，能报 500 部而文件只有一百多份。现在两边出自同一份清单，说导出多少就是多少。
- **导入未打开过的本子会丢译名** —— 模板里填好了译名，导入时因为找不到对应篇目被当成「匹配不上」丢掉。现在会先按该目录走一次正常的刷新，由扫描器建好篇目（页数、日期、编号都和平时刷新一致），再把译名写进去。所以从没打开过的本子也能直接填好导回去，第一次打开时译名就已经在了。

安全边界保留着：只有磁盘上确实存在、路径就属于该目录的文件才会被创建；手改模板凭空编出来的篇目会被忽略，不会写进库。

## 📚 本地库菜单：导入导出译名

本地库右上角菜单里，「导入本地」下面多了一项**「导入导出译名」**，和「设置 → 数据与存储 → 导入导出译名」是同一个界面：

- 导出整个本地库（JSON / CSV，可勾选「仅导出含空译名的漫画」）
- 导入整个本地库
- 批量导入章节译名

只在本地源显示，在线源不会出现这一项。

## 下载哪个包

| 文件 | 用途 |
|---|---|
| `MihonVienna-2.2.5-arm64-v8a.apk` | 手机 / 平板，绝大多数设备选这个 |
| `MihonVienna-2.2.5-x86_64.apk` | 安卓模拟器，电脑上跑模拟器选这个 |
| `MihonVienna-2.2.5-armeabi-v7a.apk` | 老旧 32 位设备 |
| `MihonVienna-2.2.5-universal.apk` | 全架构，体积最大，前三个装不上时再选 |

`vienna` 版保留原有应用 ID，可以直接覆盖安装，数据不会丢。
