# Mihon Vienna 2.4.3

> 修复老设备本地库遇到特殊 emoji / 0B 篇目连累整库打不开的问题，补齐本地筛选、详情多选、阅读器删页与音声播放的边界修复；启动迁移移出主线程，快速滚动条按列表长度缩放。

**覆盖安装即可，不用卸载。** 签名与包名 `app.mihon.dev` 不变。这一版重点修的是本地库异常文件读取、篇目移动/删除与阅读器删页提交的数据安全问题；从 2.4.2 升级没有数据库结构迁移（仍为 schema 30）。

---

## 本地库：异常文件隔离与数据安全

以前在部分老平板和外置存储上，只要本地合集里混进带有特殊 emoji 或显示为 0B 的异常篇目，`find` 扫描非零退出或归档探测抛错就会让整个本地库列表建不出来。现在：

- **扫描与建表隔离** —— `LocalSourceFileSystem` 并发排空子进程 stderr，命令非零退出时保留已经读到的有效路径，并对单条异常目录降级走 NIO 遍历；作品目录建表按作品隔离异常，0 字节直接文件短路跳过归档读取，单个坏文件不再拖垮整库。
- **SAF 与同步索引防护** —— 文档提供器暂时返回空结果时不再误清空既有封面或列表，`FileNotFoundException` 归类为目录缺失；篇目移动、删除和导入后的同步索引与封面迁移改为事务完成后提交，补齐有序互斥锁、点开头目录键名与临时目录递归清理。
- **筛选、多选与大库查询** —— 统一本地浏览的空合集与「隐藏已在书架中的作品」筛选语义；修复详情页切换多选时截断可见篇目列表的问题；章节与历史仓库的 SQLite `IN` 查询按 500 条分块，大批量标记或同步不再触碰 SQLite 变量上限。
- **归档扫描与搜索** —— 本地归档的元数据与页数合并为单次遍历读取；本地篇目搜索改从当前索引数据刷新。

## 阅读器与音声播放

- **删页提交不丢** —— 阅读器延迟删页的数据库更新改为不可取消的 IO 作用域，刚删完页就退出阅读器不再中断写库；事件通道改为带缓冲。
- **翻页与切屏保持页码** —— 单页式区分用户主动翻页，条漫离散滚动补齐落位，切换阅读模式或旋转横竖屏时保留当前正在读的页码。
- **音声播放稳定性** —— 修复切换音质时的崩溃与代际竞态，补齐曲目树失效恢复失败时的兜底与 `release()` 清理；播放页界面状态改用 `rememberSaveable`，切后台回来不再重置。
- **进度条与手势恢复** —— 音频进度条、迷你播放条、阅读器悬浮条与音量条在手势被系统打断取消时解除拖动锁死，不再卡住不跟随播放；视频区长按 2 倍速在松手、退出或组件销毁时恢复原速；收藏排序补齐下载量降序，锁屏控制同步当前倍速。

## 界面、滚动与启动

- **启动不阻塞主线程** —— 数据库迁移与启动初始化移出主线程，Activity 挂载后再读取启动状态。
- **按长度缩放的快速滚动条** —— 书架网格、书架列表与作品详情页的篇目列表，右侧快速滚动滑块高度改为按总长度比例缩放，拖到底部对齐末项。
- **详情标题保留选中** —— 漫画与音声详情页标题在界面重组且内容不变时保留系统文字选区，长按复制不再被突然取消。
- **图标、弹窗与文案修正** —— 修正导出/导入和「我的清单」图标语义、本地已读复核着色、标记列表多选顶栏与底栏、阅读页操作弹窗改为两行排布、更新弹窗按钮改为自动换行；去掉多余的成功 Toast，提高音频缓冲转圈对比度，补齐密码框无障碍名称；同步繁中支持页说明，清理 15 条未使用的 i18n 文案键。

## 工程维护

- 清理 11 处零调用死代码，Detekt 基线从 390 条缩减到 387 条，并把 Detekt 检查接入 GitHub CI。
- 5 处重复的音频播放/缓冲按钮合并为共享组件，4 处重复的本地篇目名索引 JSON 读取统一为 `LocalChapterNamesIndexStore`（磁盘格式保持不变），本地文件传输基础操作抽离至 `LocalFileTransferOps` 并补充单测。

## 本版未验证

- 真机验证只在 Redmi M332BF 上覆盖安装并操作确认；老平板真实文件系统上的特殊 emoji / 0B 文件、外置 SD 卡、文档提供器（SAF）实际授权目录以及其他厂商 ROM 未在真机实测，相关保护由单元测试覆盖。
- 音声在线接口因发版前上游后端持续超时，本版未在真机跑通在线音频拉流全链路。
- SQLite 500 条分块、SAF 异常空返回、篇目移动故障回滚由单元测试覆盖，未在真机主库上人为制造磁盘故障。

## 升级与降级

- 覆盖安装即可，包名 `app.mihon.dev` 与签名不变。版本号 `2.4.3`（`versionCode` 231）。
- 从 `2.4.2` 升级没有数据库结构迁移（保持 schema 30）。若从 `2.4.0` 或更早版本跨版升级，首次启动仍会执行 29 → 30 迁移，并在 `files/backup/` 保留迁移前的数据库快照（保留最近 3 份，只复制不自动恢复）。
- **降级不保证。** 旧版本打不开更高版本的数据结构。要退回旧版本只能卸载重装，本地库、阅读进度、已读标记和书架分类会一起丢，操作前先导出备份（`.tachibk`）。
