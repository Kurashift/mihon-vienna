# Mihon Vienna 2.3.7

> 条漫跨篇目不再跳位；更新弹窗的三个按钮各管一件事。

**覆盖安装即可，不用卸载。** 这一版没有动用户数据，也没有改签名。

---

## 条漫：跨篇目不再跳位

以前从篇目第一页往上滑、越过上一篇，画面会突然挪一下。快滑必现，慢滑看不出来。

原因是没解码的页**按整屏高占位**。视口高 2772 像素的机器上，一张 1806 像素高的图先占着 2772 的位置，真图一到就缩回去——它下方所有内容跟着位移 966 像素。慢滑时 RecyclerView 会整屏重排、以第一个可见子项为锚把位移吸收掉；快滑走的是 fling 的位移路径，不重算锚点，位移就直接漏到屏幕上。

现在每页的宽高在**生成页列表时**就读图片头拿到（`inJustDecodeBounds`，不解码像素，一张几毫秒），holder 在布局前就按真实高度定死，解码前后高度一致，不存在位移。CBZ/ZIP、目录、已下载篇目三种本地来源都覆盖。

同一条规则也覆盖了这两个会改写图片尺寸的选项：

- **裁切页边**：裁切只去掉白边，整页高度不变，裁切后的图在固定高度里居中，被裁掉的白边变成上下等分空白；
- **双页拆分 / 双页旋转适应**：按 `w/2 × 2h` 和 `h × w` 换算后再定高。

## 条漫：进篇目的第一帧

以前首帧可能在位置还没对齐时就先显示出来，随后被校正一次。现在只有两种情况下才显示：页面停在目标位置 1 像素内，或者视口已经顶到内容边界、再滚也滚不动。

顺带修掉一个会让阅读器**一直转圈或黑屏**的隐患：对齐流程原来按页面对象比较，而列表每次重建都会换一批新对象，链条会静默中断。现在按页面身份（漫画 / 篇目 / 页码）比较。

## 阅读器：不再扣住第一帧

窗口内容原来从透明开始，靠 `OnPreDrawListener` 一直返回 false 扣到首帧对齐为止。这个扣法是黑屏的根因：返回 false 会取消整趟遍历，窗口停在 `DRAW_PENDING`；释放没落在新的遍历上时窗口一直不画，首帧事务也不提交，`WindowManager` 的同步组被占住，通知栏等其它窗口一起卡。

现在窗口不扣，加载指示器改为创建时隐藏，只有首帧确实慢的时候才出现——快进篇目不再闪一下转圈。

## 更新弹窗：三个按钮各管一件事

以前是「忽略更新」和「知道了」。两个都读不出区别：一个只跳过当前版本，另一个只关掉本次，而"下次启动还问不问"这层差异按钮文案承载不了；「知道了」还和点弹窗外面完全等价。

现在：

| 按钮 | 行为 |
| --- | --- |
| **不再提示** | 关掉启动弹窗，永久生效 |
| **跳过这版** | 跳过当前版本，出现更新的版本时再提示一次 |
| **更新** | 下载并安装 |

除这三个按钮，还有第四种关法：**点弹窗外面，或者按返回键**。它只是把这一次关掉——留在应用里不会再冒出来（进出阅读器也不算），但**退出应用再打开会再问一次**。以前这种关闭会被记到进程结束为止，于是看起来像"什么都没点，弹窗自己消失了、重启也不回来"。

要让弹窗彻底不来，用「不再提示」。它在「关于」里对应一个「启动时提示新版本」开关，随时能开回来；点完「不再提示」也会提示这一点。
