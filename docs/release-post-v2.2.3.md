# Mihon Vienna 2.2.3

> 小版本：ASMR 播放器的循环补成三段，详情页的删除文案改成合集口径。

---

## 🎧 ASMR：循环有三档了

播放器的循环按钮以前只有开和关，而且都是单曲循环。现在点一次换一档：顺序播放 → 单曲循环 → 列表循环，每档有自己的图标，不用再猜现在是哪一档。

---

## 📖 详情页：删除说的是合集

本地漫画详情页右上菜单里的「删除全部篇目」改成「删除该合集」，点开后的确认框也改成「删除《xxx》合集的本地文件？」。删的一直是整个合集目录，文案现在和实际行为一致。

---

## 下载哪个包

| 文件 | 用途 |
|---|---|
| `MihonVienna-2.2.3-arm64-v8a.apk` | 手机 / 平板，绝大多数设备选这个 |
| `MihonVienna-2.2.3-x86_64.apk` | 安卓模拟器，电脑上跑模拟器选这个 |
| `MihonVienna-2.2.3-armeabi-v7a.apk` | 老旧 32 位设备 |
| `MihonVienna-2.2.3-universal.apk` | 全架构，体积最大，前三个装不上时再选 |

`vienna` 版保留原有应用 ID，可以直接覆盖安装，数据不会丢。
