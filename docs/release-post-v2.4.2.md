# Mihon Vienna 2.4.2

> 撤销胶囊换成应用级，切标签页也不中断；阅读器齿轮面板收成三栏，侧栏箭头、页码和细轨对齐；本地库导入页重做，同名归档可替换；统计把本库和阅读记录分开；音声作品里的视频版现在出画面；7z/cb7、tar/cbt 章节也能删页。

**覆盖安装即可，不用卸载。** 这一版没有改签名。第一次启动会把数据库从 schema 29 迁移到 30，迁移前在 `files/backup/` 留一份快照。

---

## 撤销：切标签页也不中断

2.4.0 的撤销胶囊挂在各自页面的 Scaffold 上。切到另一个标签页时页面被销毁，倒计时跟着没了。

现在由 `UndoPillService` 和 `MainActivity` 的 `UndoPillHost` 统一承载：消息和撤销动作交给它，倒计时在服务里走。详情页、书架、更新、历史、个人清单、已读完篇目、分类页的撤销都走这条路。副作用是这些撤销不再依赖页面 ViewModel 的生命周期——历史恢复改成挂起函数由服务调用，离开页面后点撤销依然生效。

位置也统一了：和本库页底部导航栏的落点对齐（`BottomNavFabLift`），标签页、推入的页面、阅读器用同一个高度，不随导航栏伸缩变化。

同一动作只留一条。网格里左滑切换已读时，`markChaptersRead` 已经发出带篇目数量和撤销的胶囊，滑动分支又补了一条「已标记为未读」；撤销搬到应用级之后两条不再互相顶掉，于是同一次滑动会在屏幕底部画出两条一模一样的胶囊。现在滑动分支那条删掉，`chapter_marked_read` / `chapter_marked_unread` 两条文案也一并移除。

胶囊替换时的动效也改了。以前 `AnimatedContent` 会把新旧两个内容同时画出来：旧的往下淡出、新的往上滑入，默认的 `SizeTransform` 还在插值容器尺寸，160ms 内看着像两个弹窗叠在一起，退场的那条还能点到撤销，点它撤销的是新那次操作。现在撤销胶囊和普通提示共用 `PillHost`，替换只换文案，不做两段过场。

## 阅读器：三栏面板与对齐的侧栏

齿轮面板从两组长列表收成三栏：**阅读**、**显示**、**操作**。默认打开「阅读」，模式、方向和裁边排在最前，低频选项留在各栏的折叠组里；单选行显示当前值，选中即生效。面板最高从 75% 屏高提到 85%，内容底部留 16dp。阅读器设置页里「条漫」「导航」这类连着出现、中间没有任何条目的分组标题删掉了。

侧边进度条整组对齐：上下篇箭头、页码和细轨居中对齐。横屏开着应用内播放器和音量条、或调大系统字体时，剩余高度不够就整组移到底部，已保存的侧边偏好不变；收起播放器、空间够了再回到原来那一侧。同一时间只有一条页码进度条，单页篇目不显示空轨。「始终显示篇目过渡页」从「操作」和条漫设置移到单页式设置，和「画面适配」相邻。

## 条漫宽图：双击两档

极宽的图双击时，以前两个目标档位会被限到同一个大小，等于没有切换。现在先算两个可达档位再动画。普通横屏仍是满高与八成高两档；双指缩放后双击先回到标准档。动画可以反向，也会被双指、窗口变化和页面销毁取消，旧的完成回调不再把画面拉回去。

## 本地库：导入页、同名替换与 0 篇合集

导入页重做：没选来源时只有两个选择入口，选好之后才显示目标合集、折叠的选项和底部按钮，也不再一进来就弹键盘。多选文件后填合集名、再打开「选择已有合集」返回，文件和名称都保留。选一个含多个合集的目录时，提交前会校验分组目标——把两个不同合集改成同名，「导入」不可点。开着「导入成功后删除原件」再收起选项，底部按钮直接写「导入并删除原件」。

同名导入只确认一次，默认跳过；勾选「替换已有文件」才替换能唯一匹配的同格式归档。新文件先校验再原子替换，不支持原子替换的存储不覆盖。替换不重建篇目记录，阅读进度、已读、书签、标记、译名和手选封面都在。

合集里一篇都不剩时，只要文件夹还在，它仍留在「全部」，进度显示 `0/0`，也能按标题搜到。删完篇目时可以勾选「同时删除空文件夹」，会列出一并删除的封面和元数据；删掉之后自动回到「本库」并显示结果。仅通过文档提供器访问的目录没有非递归删除保证，这种情况保留目录。散页合集默认只删正文图片。

刷新不再把暂时读不到的目录当成删除：不完整刷新沿用上次确认的条目，卡片不会先消失再回来。刷新时顺带生成缺失的封面，移动过的篇目保留原 ID，进度和标记跟着走。

## 统计：本库与阅读记录分开

阅读历史拆成两份：当前进度一份，累计的阅读认定和时长另一份。

- **阅读概览**统计本地和在线的实际阅读，不要求加入书架，也包含已经移走的内容。概览单行四项：读过作品、全部读完、已读篇目、累计时长。
- **本库**只数最近一次确认的完整列表，与当前搜索、筛选和分页无关；**书架**只数主动收藏的作品。两者会重叠，不能相加。
- **在线下载**从书架卡片中间移到分隔线下的小行，范围是下载管理器里的全部在线下载，导入的 CBZ 不计入。

清空观看进度只重置当前续读，保留累计认定与时长。清空阅读历史只隐藏列表，时长和认定不动；撤销只恢复这次隐藏的条目，不覆盖之后的新阅读。删除文件、删除本地条目、移出书架都不清累计记录。标为未读撤回该篇的完成认定，但保留实际阅读时长；重新读完可以再次计入。

## 音声播放页：带画面的曲目

DLsite 的「動画版」「影片版」在接口里是普通 `audio` 节点，以前播放页只出声。现在这些 mp4 出画面：

- 封面位换成媒体舞台，`TextureView` 播放，8dp 圆角，比例动画和页面转场跟着走。视频不进 512 MiB 的音频缓存，改走 `ProgressiveMediaSource` 直接流式读取——一个 1 GiB 的作品写进缓存会把正在听的音频全挤掉。
- 视频轨只在播放页有输出面时启用。阅读器悬浮条、队列页、后台和息屏只出声。
- 同名 wav 和 mp4 不再互相顶掉：视频作为同一曲目的第二行保留，字幕共用。
- 设备解不了编码时只禁用视频轨、保留声音并提示「该视频无法解码，仅播放音频」，不跳曲。视频起播的缓冲超时从 20 秒放宽到 60 秒，只报错不跳曲。
- 全屏：手机横屏、隐藏系统栏、控件 3 秒淡出、点画面唤回，返回键先退全屏；全屏内可以切倍速，退出按钮在控制栏里。
- 画面手势：单击显隐控件或切换字幕布局，双击播放／暂停，长按临时加速（当前倍速 ×2，上限 3×），左半竖滑调窗口亮度、右半竖滑调媒体音量，顶部胶囊显示当前值。
- 播放队列改成手风琴：展开一个作品时其余收起，任何时候只有一个作品展开。

## 搜索、面板与「更多」

搜索时页面自己的按钮不再占着输入框右边：点放大镜进入搜索后，顶栏只剩返回、输入框和清除。来源浏览那页原来返回加五个图标占掉 288dp，360dp 的屏只剩 72dp 给输入框。确实影响结果集的按钮（书架的「筛选」）走新的 `searchActions` 槽位。搜索历史下拉从「聚焦就展开」改成「输入框为空才展开」，一进搜索不再盖住半屏结果。

底部面板贴住屏幕底边：窗口铺满全屏，手势条的安全区挪到 `Surface` 内部，底色铺到屏幕底边、内容停在手势条上方；手机态只圆上面两角，键盘弹出时整块面板抬到键盘上方。走 `TabbedDialog` 的五个面板和追踪信息面板一起生效。

「更多」里的阅读设置改为按模式切换：进入的是单页式还是条漫设置，按当时编辑的模式决定，返回保留搜索词和滚动位置。书架清单与备份操作不再藏在两层菜单里，导出书架清单、备份与还原各占一行。

## 稳定性与数据安全

- **备份**：逐部读写漫画，不再同时保留全库篇目和完整字节数组。恢复前完整预检到文件末尾，检查通过才写库；分类先恢复，标记在漫画与篇目完成后按稳定身份恢复。好本子标记直接查持久化数据，旧备份没带的排序和篇目元数据保留。封面按作品继续恢复，图片编码完整后原子替换。
- **下载**：暂停后继续先等旧任务退出，旧任务不能再停掉新一轮下载。启动恢复、扫描、改名和删除按顺序提交完整索引，缓存原子替换。
- **扩展更新**：按仓库签名选更新并校验下载包身份，私有更新原子替换旧文件，取消能中断网络。多图源展示与真实包名保留。
- **章节刷新**：来源同步只更新来源字段，已有篇目 ID 和用户数据保留。下载改名记录回执，数据库或文件操作失败时逆序撤回。
- **阅读计时**：切章和暂停时同步取走计时，保存期间保留篇目资源；阅读器暂停后，已经开始的篇目加载完成不会再重新启动计时。
- **章节拖拽**：按了但一张卡片都没换位时，松手不再无条件写整份 `custom_order`，也不会把排序方式改成「手动」。提交前先按落点对齐。
- **已下载篇目多选底栏**：选中已下载的网络篇目并显示删除入口时，底栏读取下标 5 越界崩溃；改为按按钮身份记录唯一展开标签。
- **内置网页**：跨主机跳转不附带原图源请求头，过滤 WebView 不支持的请求头；网页渲染进程退出后关闭失效页面并释放等待任务。详细日志始终遮蔽 Authorization 和 Auth。
- **全局搜索**：5 路并发保留，不再为每个页面建独立线程池；结果合并与排序读同一次原子更新。
- **重复漫画检测**：空标题和全空格标题不再匹配整个书架，仍可通过追踪服务识别重复项。
- **分页阅读器**：双页拆分按篇目分别保存；相邻篇目在首次布局前加载完成时保持当前页。
- **7z/cb7、tar/cbt 删页**：按归档自身格式写回，`.cb7` 仍是 7z、`.cbt` 仍是 tar。tar 条目直接复制不压缩；7z 由 libarchive 重压（LZMA2、单个固实块），大包明显比 ZIP 慢。rar/cbr 仍然只读。

## 本版未验证

- 真机验收集中在一台 Redmi M332BF。平板布局、其他厂商 ROM、SD 卡与外置存储都没有实测。
- 音声视频只在一个 1 GiB、`moov` 在文件尾部的 mp4 上验证过逻辑；全屏手势、挖孔区留白、编码失败回退需要真机确认。
- 备份的自动测试覆盖损坏输入、取消与顺序，但设备上的完整恢复（含封面与标记）没有走完一遍。
- 统计迁移在真实 SQLite 上用 3000 级别数据验证过，设备上 553 部作品 / 4036 个篇目的迁移耗时没测。
- 本地库：文档提供器（SAF）的删除与原子替换、导入页在真机上的键盘避让和大字号排版未实测。
- 7z 删页在真机上的重压耗时没测；大包会比 ZIP 慢，这一点只有结构上的结论。
- 内置网页没有在真机终止渲染进程，也没有在 Cloudflare 页面上验证。
- 章节刷新、扩展更新、下载重启的故障注入只在单测里做，没有在设备上制造磁盘故障。

## 升级与降级

- 覆盖安装即可，包名 `app.mihon.dev` 与签名都不变。版本号是 2.4.2：上一版 2.4.0，中间没有 2.4.1。
- 这一版把数据库从 schema 29 迁移到 30（阅读记录拆分）。迁移前会把整份数据库复制到 `files/backup/pre-migration-230.db`，保留最近 3 份；只复制不恢复，代码里没有会动用户数据的入口。
- **降级不保证。** 旧版本打不开新 schema。要退回 2.4.0 只能卸载重装，本地库、阅读进度、已读标记和书架分类会一起丢，先导出备份（`.tachibk`）。
