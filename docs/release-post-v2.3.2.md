# Mihon Vienna 2.3.2

这一版是修复为主，没有新功能。

**直接从 2.3.1 覆盖安装即可，不用卸载，数据都在。**

升级后第一次打开时，应用会自动修正一处历史数据错误（见下），不需要你操作。

---

## 页数 / 进度显示错误已修复

有一处数据写反的 bug：篇目的**总页数**和**阅读进度**在写入时互换了位置。

表现是：一本 22 页的书读到第 2 页，却显示 `1/2`；读到第 1 页显示 `0/1`；没读过的干脆没有分母。更糟的是，打开这类篇目会把进度清零。

现在：

- 写入的两处都改成了按名字传参，不再写反
- **已经写反的历史数据会在升级后一次性自动修正**（靠篇目自带的页数记录做指纹，不会误伤正常数据）
- 用这一版**恢复旧版备份**时也会识别并纠正写反的值
- 恢复备份时，设备上损坏的进度不再覆盖文件里的正确值

## 本地库修复

- **一个损坏的篇目文件不再拖垮整部作品**：以前一个文件读不了，整部作品的篇目列表都建不出来。现在坏文件会作为「只有文件名」的条目保留，仍可见、可删
- **空扫描不再落盘**：重装后本库可能空着、并且最长一天不恢复——原因是空的扫描结果被写进了索引。现在空扫描不动索引，目录可读时会自动重扫修复
- **导入文件名含非法字符不再失败**：预览和实际导入现在用同一套命名规则（去空白、限长、给扩展名留位），外置卡（FAT / exFAT）上不会再因为文件名被拒而报「Cannot commit imported chapter」
- **刷新失败不再误报「书架有更新」**：以前横幅让你去菜单刷新，而刷不了的原因正是同一次失败
- **被拒的来源提示不再赖着不走**：选错过一次之后，那行红字会一直挂到退出页面，即使后来已经选对了

## 阅读器修复

- **条漫从上一篇滑进来的篇目不再丢进度**：以前正向滑入一个读了一半的篇目，会把进度覆写成你滑到的那一页。现在会守住已存的进度，直到你真正滑回那一页
- **刷新时转场卡不再跳位**

## 中文修复

- **繁体中文补了 149 条缺失文案**：本地库、清单、篇目译名、音频这些界面此前在繁中环境下会显示英文
- **简体中文修了若干误译**，并统一了术语（章节→篇目、名单→清单等）
