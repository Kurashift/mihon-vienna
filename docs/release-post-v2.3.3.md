# Mihon Vienna 2.3.3

这一版集中在三件事：无痕模式改成常驻、在线篇目的篇目行重新排过、音声搜索重做。

**直接从 2.3.2 覆盖安装即可，不用卸载，数据都在。**

---

## 无痕模式：开了就一直开着

以前每次冷启动应用，无痕模式都会被自动关掉。想一直用它的人，等于每次打开都要再开一次。

现在不会了：**开启后重进应用仍然是无痕状态**，只有你自己去关它。

同时去掉了它以前那些存在感很强的东西：

- 顶部那条横贯屏幕的「无痕模式」提示条
- 状态栏的染色
- 常驻通知和它自己的通知渠道（升级时系统会清掉旧渠道）

替代它们的是**「更多」图标上的一个小眼镜**。它画在图标自己的颜色里、落在三个点上方那块空处，像是这个图标本来的一个变体，而不是贴上去的角标：

- 开启无痕时淡入并轻微放大，关闭时淡出
- 你点「更多」或从「更多」离开时，它跟着三个点的那下弹跳一起动
- 本库的已读、好本子、标记这些图标各有自己的变体，眼镜就是同一个路子

**历史页在无痕开启时会多一行小字**说明不记录历史和进度——因为那是你唯一能察觉「记录没进来」的地方。有历史时它在列表最上面，没有历史时它就是空状态那行字。

## 篇目行：进度值回到标题那一行

在线篇目的行以前是这么排的：标题一行，汉化组名一行，右边一列竖着放已读、红心、旗子、书签、下载按钮，进度值在最底下。结果就是每个篇目的进度值和左边标题不在一个水平线上，行与行之间参差；点开一个篇目让进度值出现，整行还会往上跳一点。

现在无封面的行改成两行结构：

- **第一行：标题在左，进度值在右，按同一基线对齐**，长标题也只在自己的宽度内截断，不会把进度值挤走
- **第二行：汉化组名在左，标记靠右**，正好落在进度值正下方。这一行只在有内容时才排——普通在线篇目就是干净的一行标题加进度
- 整行顶部对齐、标题位置固定，所以打标、取消、进度值出现都不会再让标题和进度上下移动

有封面的行（本地篇目、下载过的篇目）右侧空间充裕，标记仍留在右边那一列，位置也固定。

无封面行上那个单独的「已读勾」也去掉了：**读完的篇目靠整行变暗和 `24/24` 这样的进度表示**，不再多一个勾。另外，「已下载」的图标从实心圆圈勾换成了下载完成的图标——以前它和已读的那个勾长得太像，扫一眼分不清。

## 音声搜索

三处改动，都是围绕「搜不到本该搜到的东西」。

**标签页里再搜索，不再丢掉标签。** 以前在某个标签的结果页里输入关键词，页面的标签只在一种情况下保得住：本地词典正好把这个标签名解析成了一个 id。词典还没加载、名字是别名形式、或者有同名歧义时，这个页面实际上就是一次普通关键词搜索，再搜一次等于把标签整个替换掉，清空搜索框还会掉到推荐流。现在标签按名字钉住，页面上的搜索是在这个标签里再筛，清空搜索框回到标签自己的列表。

**搜索词的简繁变体，改写为词典里的写法。** 服务端不做繁简折叠：繁体「處女」只有 2 部作品，而标签的简体别名「处女」有 2640 部。现在输入会先跟标签、声优、社团三本词典比对（简繁、新旧字形、全半角、大小写），只在归一化之后才匹配上的词，会改写成词典里的那个写法再发出去。

**搜索恢复并集语义。** 服务端的自由文本索引本身就同时覆盖作品标题和标签名——裸词「耳かき」有 4798 部，而标签筛选是 4533 部，标签命中的作品全在这 4798 部里面。所以搜「耳かき」现在同时给你标签命中的和标题里带这个词的。要严格只看某个标签，走标签分类页。

刻意没有做的是盲目繁转简：「愛」5235 部、「爱」3553 部，硬转会静默少掉一批结果。只有能在词典里找到对应写法的词才改写，其余原样发出。

## 音声详细页

- **从播放页、迷你播放栏、历史、播放列表、漫画快选、阅读器移交这些入口进详细页时，标签和声优不再整块消失。** 这些入口带过来的是只有 id、标题、社团、封面的快照；现在缺标签时会按 id 补拉一次元数据，收藏也改用补全后的记录。拉取失败不报错，页面照常能用
- **标题支持框选**：长按进入系统选区，菜单里有「复制」和「搜索 ASMR」，都作用于你框选的那段文字；单击仍然是搜索整个标题
- 播放页的曲名、详细页和播放页的社团名都能长按复制，播放页的社团名点击跳该社团的作品列表

## 阅读器：读完的篇目从第一页重开

以前一个篇目读完后，再点开是从最后一页打开的。重看等于从结尾开始翻。

现在读完的篇目和没读过的一样**从第一页打开**；读了一半的仍然接着上次的位置。已读标记和已存的进度都不动。

## 首次使用引导

左下角那个按钮（点按回到上次在看、上拖好本子、右拖随机一本）以前没有任何说明。现在第一次进本库时，它会用三个小气泡把三个手势标出来，气泡就摆在各自动作发生的位置，背景压一层暗色、按钮处留一个洞。点屏幕任意处翻到下一个，返回键直接结束。

这个引导的标志是这一版新加的，所以**升级后第一次进本库也会看到一次**。空库不弹——等列表和按钮出现（最多 5 秒）再显示，并且不记这次已经看过，下次进来还会提示。

阅读器的点击区域图上多了一行小字写明滑动方向（上下翻页模式是上/下，条漫是左/右），画在 MENU 标签正下方。只对本地作品显示，因为随机的池子只在本地。它就画在原生那张点击区域图上，出现的时机和那张图完全一致——首次打开阅读器、在阅读设置里换导航方式，或者开启了「启动时显示导航模式」。已经用过阅读器的人不会因为它而多看到什么，除非自己去重置引导。

设置里「高级」多了**「重新显示功能引导」**，点一下把这两处引导（以及阅读器的点击区域图）恢复成未看过的状态，并弹一个短胶囊「功能引导已重置」。

## 条漫拖进度条到底，能进下一话

条漫把进度条拖到当前话末尾时，以前会卡住划不下去，得自己手动切下一话。

原因是拖动落点走的是另一条路径，绕过了「快到末页就预载相邻话」那段逻辑；下一话没加载时，列表末尾是转场卡，而转场卡永远滚不进视口成为选中项，预载也就永远不开始。现在落点会显式预载相邻话。翻页模式不受影响。
