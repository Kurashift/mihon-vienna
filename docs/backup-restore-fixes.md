# 备份与恢复修复

日期：2026-11-17。对应 [完整性核查](backup-integrity-audit.md) 的三处缺口。本次不迁移数据库，不提升版本，不构建安装包，不操作手机主库。

## 改了什么

| 情况 | 以前 | 现在 | 可能感受到什么 |
| --- | --- | --- | --- |
| 刚启动就备份“好本子” | 可能把尚未加载的空界面状态当成标记快照 | 备份先处理旧标记迁移，再查询持久化标记；不等待界面订阅 | 正常备份入口和操作不变；冷启动时有数据可读就导出 |
| 标记对应作品或篇目读取失败 | 普通读取异常可能被当成条目已删除，跳过标记 | 确认已删除的条目仍跳过；数据库读取失败或取消会向备份任务传递 | 读取故障会显示原有备份失败结果，避免生成遗漏标记却显示成功的备份 |
| 旧备份没有排序或 memo 字段 | 篇目排序可能从 17 变成 0，已有元数据可能被空对象覆盖 | 字段缺失时保留目标篇目的原值；新篇目仍使用默认值 | 恢复旧备份时保留当前手动排序 |
| 新备份主动保存排序 0 或空 memo | 字段缺省与主动重置无法区分 | 创建器明确写出 0 和空对象，恢复可执行主动重置 | 当前备份仍能恢复用户设置的默认排序 |
| 篇目自定义封面无法恢复 | false 返回值被忽略，异常只记日志 | 尝试后续封面，汇总失败篇目及原因，交给原有恢复错误报告 | 只有失败时，完成通知的错误数量与日志增加记录；正常操作不增加提示 |
| 封面写入失败或取消 | 写入路径先删旧图，再改名或复制新图 | 新图编码完整写入并检查后，才原子替换旧图；失败保留旧图并清理临时文件 | 原有封面不因一次失败的恢复写入而丢失 |

封面文件恢复发生在数据库提交后。个别封面失败不会撤销已经恢复的进度、译名和书签，也不会阻止后续作品及最终标记恢复。取消仍停止后续写入，不被转换为普通图片错误。

## 兼容范围

- Protobuf 字段编号与类型不变，不修改 `.tachibk` 外层格式。旧文件仍可读取，新文件仍可被测试中的旧版读取器接受。
- 篇目排序与 memo 的“字段不存在”在备份模型内保留为 null；生成数据库章节时才应用默认值，恢复已有章节时使用目标值。
- 某些旧版本导出排序 0 时根本没有写出这个字段。文件里没有的信息无法推断，因此这种旧文件按“缺失，保留设备排序”处理。修复后新建备份会明确编码 0。
- 标记仍使用来源、作品地址和篇目地址关联，不把旧数据库数字 ID 当成恢复身份。已确认删除或已移到其他作品的失效标记不会错误关联到旧作品。
- 漫画原文件、下载和整部作品的自定义主封面仍不包含在元数据备份里，需另行保留文件。本次没有扩大备份范围。
- 无效或超过 10 MiB 的篇目封面在导出时仍可能被现有策略跳过；本次补齐的是恢复失败报告，未改导出限制。需要单独评估导出失败的呈现方式。

## 影响面检查

检查了备份创建器、专用标记创建器、恢复器、设置备份排除规则、章节查询 mapper、普通标记与“好本子”存储、篇目封面的设置、恢复和自动生成调用方。没有新增第二份标记存储或修改界面状态流。

封面的文件替换由设置封面、恢复封面和自动封面生成共同使用。自定义封面正常保存后仍按稳定篇目 ID 读取；自动封面缓存的键与有效文件命名不变，普通读取缓存不触发新的目录扫描。文件暂存路径独立，完整写入后替换，不采用先删除目标再复制的恢复分支。

本次没有修改目录身份、扫描阈值、目录索引、批量移动、目录重命名或本地库筛选。既有相邻测试随完整测试执行；没有声称这些操作都已在设备上重新验收。

## 手动回归

本批主要是保存与恢复行为，阅读器手势和滑动规则没有调整。交付源码后尚未安装新包；以下步骤供后续安装验证时使用。

1. 在少量测试漫画副本上设置篇目译名、书签、“好本子”和手动排序，读到中间一页后退出。记下这些状态与续读位置。不要用真实主库制造删除、改名或故障。
2. 正常关闭再打开应用，直接进入“更多 → 设置 → 数据与存储 → 备份与还原”创建备份，保留作品、篇目、历史和应用设置等默认项目。预期得到 `.tachibk`，没有新增等待页面或确认弹窗。冷启动时序由自动测试判断，不要求用户抢速度操作。
3. 仅在独立测试设备或隔离环境中放好漫画副本并恢复，检查对应篇目的译名、书签、“好本子”、排序、历史和续读位置。预期状态属于正确篇目；重复恢复不让历史时长翻倍。没有隔离环境时跳过恢复，不在主库反复导入旧备份。
4. 在测试副本的阅读器中使用现有菜单选择一张篇目封面，再正常备份与恢复。预期目标篇目显示同一张封面；设置后退出再进入也能显示。写入失败、坏图、取消与错误报告由自动测试覆盖，不要求破坏图片或填满手机。
5. 正常连续下滑、反向翻回、跨篇目、拖进度条、缩放，退出后重新进入。预期阅读手感保持原样，续读位置正确。这些设备手感仍待用户确认，agent 负责日志与崩溃检查。

回归现象包括：排序被旧备份重置、已保存的标记不见、状态关联到错误篇目、有效进度倒退、历史时长翻倍、封面失败却没有错误报告，以及阅读白块、跳位或缩放异常。整部作品主封面未包含在元数据备份中属于范围限制，不能据此认定篇目封面恢复回归。
