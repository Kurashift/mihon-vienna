# 阅读统计与记录保留

本次变更迁移阅读历史数据：当前文件和续读进度与保留的阅读统计分开。不会重建本库，也不会恢复旧版本已经删除且没有备份的时长。应用版本号不变。

## 数字的范围

| 区块 | 范围 |
| --- | --- |
| 阅读概览 | 本地和在线阅读，不要求加入书架；包含已经移走的内容 |
| 本库 | 最近一次确认的本库完整列表中的作品和篇目，与当前搜索、筛选和分页无关 |
| 书架 | 主动收藏的本地与在线作品 |
| 篇目 | 全部保留记录中的已读篇目，以及下载管理器中的在线下载篇目 |
| 追踪 | 书架作品在当前已登录服务上的追踪 |

本库与书架可能重叠，不能把它们相加。未知的本库指标显示“—”，已确认空库才显示 0。普通进入统计不扫描目录、不打开压缩包、不生成封面。

## 操作规则

- 有效部分阅读计入阅读过的作品，不计入已读篇目。
- 读完或手动标为已读，每个篇目只计一次；手动标记不生成阅读时长。
- 标为未读撤回该篇的完成认定，保留实际阅读时长。重读再次完成后可以重新计入，时长继续累计。
- 清空观看进度只重置当前进度，保留累计阅读认定与时长。
- 清空阅读历史只隐藏历史列表，保留累计阅读认定与时长；撤销只恢复本次隐藏的条目，不覆盖后来阅读。
- 删除文件、删除本地条目、移出书架不清累计记录。
- 全部读完要求至少一个已知篇目、全部已认定完成，不要求来源标注完结。移走未读篇目不能凭空让整部作品完成；发现新篇目会扩充分母。

## 备份边界

阅读记录包括隐藏、未收藏、已删除内容及已经撤回已读认定的条目。重复恢复同一记录不重复增加时长；较旧备份不能复活后来明确撤回的已读认定。

本次面向单设备备份和迁移。绝对累计时长合并不能精确相加多台设备在共同备份后分别新增的时长。旧备份没有保存的时长、旧撤回顺序，以及没有身份映射的外部改名，不能推断补齐。

## 页面布局

阅读概览采用上游的单行三列：阅读过的作品、累计阅读时长、全部读完的作品。全局已读篇目与在线下载移到篇目卡片。本库、书架和追踪仍各占一行。卡片只显示指标，不显示口径说明段落；规则保留在本文档中。

布局回归：打开“更多 → 统计”，检查概览只有一行、各卡片没有底部说明文字、全局已读篇目仍能找到；横竖屏和系统大字体下数字与标签不重叠。

## 真机回归

仅在用户要求构建安装后进行。用户操作，agent 读取日志。删除、重导入和恢复仅使用测试副本，不拿主库试故障。

1. 本库清除搜索、标记筛选和阅读筛选，对比“全部”作品数与统计本库数；加入、移出书架，只改变对应收藏指标。
2. 打开未收藏的本地测试篇目，连续下滑、反向翻回、缩放、拖进度条、跨篇目、退出续读；阅读概览更新，部分阅读不算已读篇目，跨篇与后台恢复不重复或丢失时长。在线未收藏篇目同样计入阅读。
3. 手动已读、未读、撤销：篇目数量对应变化，时长不凭空变化。清空观看进度后当前续读重置，累计认定保留。
4. 清空历史后确认列表为空、累计时长和认定保持；重新阅读，再撤销清空，确认新阅读不被旧快照覆盖，时长不翻倍。
5. 删除并重导入测试内容，随后备份恢复两次；当前本库库存对应变化，保留记录不丢、不重复累计，书签、标记、译名、封面与已有恢复行为不回归。

目录暂不可读后显示假 0、统计进入时长时间扫盘、清历史后时长减少、重导入或恢复后数量/时长翻倍、未读被旧备份改回已读，均属于回归。少量已知损坏且无法删除的文件不计入现场对数。

## 自动验证

交付前运行仓库格式检查、单元测试、SQLDelight 迁移检查、Vienna Kotlin 编译与相关本地源测试。真实 SQLite 回归覆盖迁移、外键、触发器、源同步、删除、身份重联、事务回滚；状态与备份测试覆盖撤销后新阅读、未读冲突、重复恢复和取消。最终执行结果在 PR 中记录，编译与测试通过不代表真机验收完成。
