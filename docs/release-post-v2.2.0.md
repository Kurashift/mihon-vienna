# Mihon Vienna 2.2.0 更新日志

## 🎯 操作变化

- **左下角定位按钮支持手势触发随机**：上滑随机好本子、右滑随机一部；找不到最后阅读时也会变成骰子按钮兜底，不再消失。
- **顶栏标题可以点击进入详情页**：标题右侧带小箭头提示，从历史、清单、搜索等页面点标题就能直接打开漫画详情。

## 🎧 ASMR

- ASMR 页面打开更快，分类/详情重复进入不用再傻等。
- 新增**悬浮字幕**：听 ASMR 时可以把当前字幕浮在屏幕上方，可拖动、可锁定、记住位置；播放页点「词」开启。
- 播放器界面更顺手：睡眠定时、循环、音质更好辨认；点音轨会带出它所属的文件夹。
- 播放列表支持多选移除。
- 新增蓝牙/耳机媒体键支持，锁屏/后台也能用耳机控制播放。

## 📖 阅读器

- 进入/退出阅读器不再闪白闪黑，退出也不会留黑边。
- 返回更符合直觉：从书架、历史、清单直接进阅读器后，返回会回到原列表，不再莫名跳到详情页。

## 🏠 本地库 / 历史

- 历史记录现在能显示**本库漫画的具体篇目**：展示对应章节的封面和标题，不再只是笼统的漫画名。
- 本地漫画的章节过滤隐藏了没有意义的「已下载/书签/图源」选项。
- 译名导入/导出更可靠，换机或移动文件后也能重新对上。

## 📋 清单

- 个人清单入口直接显示三个清单的数量。
- 标记清单、好本子清单改成封面网格，支持搜索、多选移除、导出文本。
- 已读完篇目页重做：按漫画汇总，支持搜索、批量撤销误标、导出清单。
- 修复点击已删除的篇目会进错漫画的问题。

## 🧹 其它修复与调整

- 修复详情页大标题滚动时消失的问题。
- 更新检查改为指向 Mihon Vienna 自己的仓库。
- 支持页文案区分“支持上游 Mihon”和个人渠道。
