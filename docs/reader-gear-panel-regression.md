# 阅读器齿轮面板回归

齿轮面板仍是三栏，现在是「阅读」「显示」「操作」。默认打开「阅读」，模式、方向和裁边排在最前；低频选项留在各栏的折叠组里。单选行显示当前值，选中即生效。已有设置、单页与条漫各自的配置，以及「更多 → 设置 → 阅读器」的入口不变。

## 真机步骤

选一个可重新导入、至少有两个篇目的测试副本。开始前记下常用阅读设置，测完后改回原值。

1. 在测试作品读到中段，打开齿轮。确认首屏能看到阅读模式、屏幕方向和裁边。给条漫和单页设不同裁边值，再来回切换：各自保留设置，不跳回篇目开头。横放手机和调大系统字体复查，文字可换行，菜单和最后一项仍可点到。
2. 切到「显示」，开关自定义亮度、换背景色、展开「滤镜」调灰度、反色和颜色。预期漫画画面立即变化且不被遮暗；合上面板或切到别栏后，阅读工具栏恢复。全屏时仅有刘海或挖孔的设备显示对应选项。
3. 在「操作」关闭点按区域，确认「点按反转」消失；重新开启后查看其原值。展开「侧边进度条」和「翻页闪光」，确认侧边进度条只有选中模式后才出现位置及高度，闪光只有开启后才出现参数。切栏再切回应保留展开和滚动位置；关闭再开回到「阅读」顶部，设置值仍在，并与应用设置一致。
4. 恢复常用设置，连续下滑、反向翻回、跨篇目，用进度条跳到中间，双指缩放后退出并重新进入。应续读到退出位置。切设置时跳页、两种模式串值、工具栏不恢复、控件截断或续读位置偏移均算回归。

本地格式检查、单元测试、数据库迁移检查及 Vienna Kotlin 编译不替代真机验收。未安装 APK 时，不据此判断布局、预览和滚动手感。
